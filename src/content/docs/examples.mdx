# Factory Examples

Each example is a real repository with its factory checked in alongside the code. Clone it, open it in your IDE, and see how skills, commands, agents, and workflows fit together on a working project.

<ExamplesList />

## What is a Factory Example?

A factory example is a complete repository, not a configuration snippet. The factory components live where your IDE loads them, next to the application they build. Each example shows:

- **The components**: which skills, commands, agents, and workflows the repository uses
- **Where they live**: the folders your IDE reads them from
- **The work they produce**: the code, specs, tests, and logs the factory has generated

## Using Examples

1. Clone the repository that matches what you want to learn.
2. Open it in your IDE and read the factory folders to see how the components are written.
3. Run a command or workflow against the repository and compare the result to what is checked in.
4. Copy the components that fit your project, then adapt them to your codebase.
